#profile-app-practice

## 概要
COACHTECH 教材 Tutorial 9-1 「Laravel基礎ハンズオン」で作成した成果物です。Laravelを利用して自己紹介ページを作成しました。

## 使用技術
- PHP 8.x
- Laravel 10.x
- bladeテンプレート

## 学んだこと
- Laravelを使用したWEBページの作成方法。
- ルーティング　→　コントローラー　→　ビュー　→ブラウザに表示される流れがわかった。

## 動作確認
- ブラウザでhttp://localhostにアクセスして環境構築できたか確認する。
- http://localhost/profileにアクセスして、プロフィールページが表示されるか確認。
